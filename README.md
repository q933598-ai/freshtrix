# Freshtrix

> **Experimental project — just a test, not intended for production use.**

Freshtrix is an experimental attempt to explore whether the desktop interface and application structure of [freshGram](https://github.com/Snowy-Fluffy/freshGram) can be adapted to work with [Larptrix](https://github.com/q933598-ai/larptix), an independent messaging project.

## Project status

This repository is a proof of concept and a learning experiment. It is **not** the main Larptrix client, is not ready for everyday use, and may be incomplete, unstable, or non-functional.

The goal is to experiment with connecting a familiar desktop messenger-style interface to a Larptrix server. No compatibility or working features are promised yet.
